# CNN Image Classification using CIFAR-10

## Overview

This project implements a Convolutional Neural Network (CNN) for image classification using the CIFAR-10 dataset.

## Features

- Data preprocessing
- CNN architecture
- Model training
- Validation
- Accuracy visualization
- Confusion matrix
- Classification report

## Technologies

- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
